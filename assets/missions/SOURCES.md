# Provenance: missions/: mission files, terrains and menu pictures

Where each file of this directory comes from (paths relative to it).
Licence, the upscaling and the layout: `docs/layout.md` (§ Provenance).

This table lists OpenTT's own files of this directory; the importer builds the rest of the asset directory from your game install (`docs/import.md`).

| file | source: how |
|---|---|
| `catalog.ron` | OpenTT's own: the menus' map list (order, worlds, the mission files that are no maps of the list; docs/modding.md) |
| `poweruptest.ron` | OpenTT's own "Power-up Test" mission (written as PowerupTest.mis, converted by `tt-convert missions`; the .mis is in git history) |
| `poweruptest.ter` | OpenTT's own: generated by `cargo run -p tt-assets --example powerup_terrain -- assets/missions/poweruptest.ter` |
| `tt1_5.ron` | OpenTT's own map "Amygdala Abyss": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt1_5.ter` | OpenTT's own map "Amygdala Abyss": generated by `cargo run -p tt-assets --example new_maps` |
| `tt2_5.ron` | OpenTT's own map "Thalamus Pass": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt2_5.ter` | OpenTT's own map "Thalamus Pass": generated by `cargo run -p tt-assets --example new_maps` |
| `tt3_5.ron` | OpenTT's own map "Cerebral Caldera": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt3_5.ter` | OpenTT's own map "Cerebral Caldera": generated by `cargo run -p tt-assets --example new_maps` |
