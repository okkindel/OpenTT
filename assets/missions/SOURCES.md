# Provenance: missions/: mission files, terrains and menu pictures

Where each file of this directory comes from (paths relative to it).
Licence, the upscaling and the layout: `docs/layout.md` (§ Provenance).

This table lists OpenTT's own files of this directory; the importer builds the rest of the asset directory from your game install (`docs/import.md`).

| file | source: how |
|---|---|
| `catalog.ron` | OpenTT's own: the menus' map list (order, worlds, the mission files that are no maps of the list; docs/modding.md) |
| `poweruptest.ron` | OpenTT's own "Power-up Test" mission (written as PowerupTest.mis, converted by `tt-convert missions`; the .mis is in git history) |
| `poweruptest.ter` | OpenTT's own: generated by `cargo run -p tt-assets --example powerup_terrain -- assets` (a flat square floor in a square bowl; one texture, terrain/dev/devgrid.png) |
| `tt1_5.ron` | OpenTT's own map "The Neverending Stream": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt1_5.ter` | OpenTT's own map "The Neverending Stream": generated by `cargo run -p tt-assets --example new_maps` |
| `tt1_5_macro.png` | OpenTT's own map "The Neverending Stream": its terrain's macro colour map (`macro_texture`), generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/) |
| `tt2_5.ron` | OpenTT's own map "Night of the Living Brains": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/halloween.rs), written as RON. |
| `tt2_5.ter` | OpenTT's own map "Night of the Living Brains": generated by `cargo run -p tt-assets --example new_maps` |
| `tt2_5_macro.png` | OpenTT's own map "Night of the Living Brains": its terrain's macro colour map (`macro_texture`), generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), then made a 256-colour palette PNG by `python3 -I tools/moon-assets/png_palette.py assets/missions/tt2_5_macro.png` (no visible change in game; 0.9 MB -> 0.13 MB) |
| `tt3_5.ron` | OpenTT's own map "The Dark Cortex": generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt3_5.ter` | OpenTT's own map "The Dark Cortex": generated by `cargo run -p tt-assets --example new_maps` |
| `tt3_5_macro.png` | OpenTT's own map "The Dark Cortex": its terrain's macro colour map (`macro_texture`), generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), 512x512 (2 m per texel) |
| `tt4_1.ron` | OpenTT's own map "Lunar Lobe" (the Moon): generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt4_1.ter` | OpenTT's own map "Lunar Lobe" (the Moon): generated by `cargo run -p tt-assets --example new_maps` |
| `tt4_1_macro.png` | OpenTT's own map "Lunar Lobe" (the Moon): its terrain's macro colour map (`macro_texture`), generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/moon.rs) |
| `tt4_2.ron` | OpenTT's own map "Cortex Craters" (the Moon): generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/), written as RON. |
| `tt4_2.ter` | OpenTT's own map "Cortex Craters" (the Moon): generated by `cargo run -p tt-assets --example new_maps` |
| `tt4_2_macro.png` | OpenTT's own map "Cortex Craters" (the Moon): its terrain's macro colour map (`macro_texture`), generated by `cargo run -p tt-assets --example new_maps` (crates/tt-assets/examples/new_maps/moon.rs) |
