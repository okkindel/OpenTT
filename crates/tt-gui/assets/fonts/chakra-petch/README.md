# Chakra Petch

The UI font of OpenTT (menu, in-game GUI and HUD), compiled into `tt-gui`
by `src/uifont.rs` (`REGULAR_TTF` = Medium, `BOLD_TTF` = Bold).

* Source: Google Fonts, `github.com/google/fonts`, `ofl/chakrapetch/`
  (`ChakraPetch-Medium.ttf`, `ChakraPetch-Bold.ttf`), unchanged.
